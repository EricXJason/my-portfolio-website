> **更新日期**: 2026-09-30  
> **使用準則**: 執行「功能點收驗收」指令時，依據本表逐項嚴格核對系統實際運作成效；需求異動時動態替換對應分類項目。

---

## 資料庫與持久化層

- [x] **雙集合架構實作**: Firestore 建立 `portfolio_fullstack_dev` 與 `portfolio_interactive_app_dev` 兩組獨立集合，完全隔離全端與互動履歷資料。
- [x] **安全防護規則**: 根目錄 `firestore.rules` 明確設定前臺訪客公開唯讀，寫入與刪除強制限定 Firebase Auth 驗證管理員。
- [x] **檔案儲存庫規則**: 根目錄 `storage.rules` 限制 `/uploads` 寫入必須通過管理員認證，且嚴格檢驗檔案小於 15MB 並符合 `image/*` MIME 類型。
- [x] **離線安全降級 (Graceful Fallback)**: 當網路斷線、未配置 Firebase 或遠端拋錯時，前端自動無縫降級讀取本地打包之靜態 JSON (`src/data/*.json`)，介面零報錯、無白屏。
- [x] **本地快取層 (LocalStorage)**: 實作 Level 2 瀏覽器持久化快取，頁面初次渲染達成秒級直出，並具備跨分頁更新監聽與自動廣播。
- [x] **一鍵種子資料同步 (Seed Data)**: 提供批次初始化腳本，可將本地最新資料一鍵寫入雲端 Firestore 集合。

## 後端 API 與商務邏輯層

- [x] **統一資料持久化服務 (PortfolioDataService)**: 封裝所有 Firestore 與 Storage 存取，對外暴露強型別方法 (`getPortfolioDoc`, `savePortfolioDoc`)。
- [x] **管理者身分鑑權 (Firebase Auth)**: 實作管理員登入生命週期監聽，於 CMS 後臺提供安全登入對話框與 Token 自動更新。
- [x] **單一真實資料源 (SSOT)**: 全站前臺元件與 CMS 編輯器皆對齊 `src/types/portfolio.ts` 領域模型契約，杜絕欄位拼寫不一致。
- [x] **多語系資料結構分離**: 嚴格隔離語系文字字典 (`zh` / `en`) 與跨語系共用結構（排序、日期、連結、標籤），避免重複維護。
- [x] **依賴安全與 CVE 零漏洞**: 透過 `pnpm.overrides` 釘選安全版本 `nanoid: ^3.3.18` 與 `sharp: ^0.35.4`，`pnpm audit` 達成 0 已知漏洞。

## 前端介面與互動狀態

- [x] **雙軌履歷路徑分流 (Dual-Profile Routing)**:
  - 存取 `/` 或 `/f`: 渲染全端工程師優先模板，聚焦 Web、API、資料庫與後端系統。
  - 存取 `/i`: 渲染互動應用工程師優先模板，聚焦 Unity 3D、即時物理模擬、電腦圖學與展示畫廊。
- [x] **前臺展示層零硬編碼**: 所有展示元件均由 `PortfolioDataContext` 提供的資料動態驅動，元件內部無寫死的分流判斷。
- [x] **三階段平滑開場載入**: 0-100% 科技感載入動畫 $\rightarrow$ 多國語系選擇視窗 $\rightarrow$ 揭開主站，且對搜尋引擎爬蟲及 CMS 預覽返回者實施自動直通。
- [x] **全功能 CMS 內容管理後臺 (`/cms`)**:
  - 支援各區塊獨立編輯、即時預覽與拖曳排序 (Drag and Drop)。
  - 具備未存檔離開警告 (Dirty Guard) 與二次確認防呆機制。
  - 採用 `React.lazy` 動態代碼分割，不增加前臺主資源包體積。
- [x] **科技感微互動與音訊系統**:
  - 自研 Web Audio API 雙音軌合成器，支援音量調節與平滑淡入淡出。
  - Canvas 全端程式碼瀑布流與自訂雷射粒子游標。

## UI/UX 設計與文字規格

- [x] **臺灣繁體中文在地化**: 專案全體介面文案、註解與說明文件 100% 使用臺灣繁體中文（「臺」嚴禁「台」與簡體字）。
- [x] **招募主管閱讀體驗優化**: 內文字距行高最佳化，文字敘述杜絕「一站式」、「賦能」等空泛假話，改以具體技術事實與量化成果陳述。
- [x] **雙模式主題 (Dark / Light)**:
  - 深色模式：賽博微光質感，個人大頭照保持 RGBA Alpha 通道透明度，容器維持 `bg-transparent`。
  - 淺色模式：明亮清爽，大頭照徹底移除黑色掃描線條紋與暗角覆蓋層，微調環境柔光與濾鏡，通透自然。
- [x] **警示與危險操作一致性**: 全站所有垃圾桶圖標、重置按鈕與狀態為隱藏 (Hidden) 的標籤，統一標註為**紅色系警示標記**。
- [x] **無障礙標準 (WCAG 2.1 AA)**: 具備合規之色彩對比度、鍵盤聚焦輪廓 (`:focus-visible`)、ARIA 標籤與 `prefers-reduced-motion` 適配。
